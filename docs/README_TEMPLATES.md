# Current Project Root README Templates

These are the exact root README contents currently generated by the source code. The placeholders are substituted at runtime.

## 1. Newly created project

**Creation path:** `IdeViewModel.createBlankProject`.

**Condition:** A new project folder is created. The method calls `ensureProjectMetadata`, then creates the standard files including `README.md`. The root README is written with the project name and the description entered in the creation flow.

**Runtime placeholders:**

- `$trimmed` is the trimmed project name.
- `${description.trim().ifEmpty { "This project was created with Android IDE." }}` is the entered description, or the fallback sentence when no description was entered.

**Exact template after substitution:**

~~~markdown
# $trimmed

${description.trim().ifEmpty { "This project was created with Android IDE." }}

## Attribution

This project was created with [Android IDE](https://github.com/godlovetikum/Android-IDE).

- **Author:** [godlovetikum](https://github.com/godlovetikum)
- **Android IDE repository:** https://github.com/godlovetikum/Android-IDE

## Getting started

Install dependencies:

~~~bash
npm install
~~~

Start the project:

~~~bash
npm start
~~~

## Project

The project entry point is `index.js`. Update this README with the purpose, setup requirements, and deployment instructions for the application as it evolves.
~~~

The source also creates a `package.json` and `.gitignore` for this blank project. Those files are not part of the root README template.

## 2. Imported or opened project without a root README

**Creation path:** `IdeViewModel.ensureProjectReadme`.

**Condition:** The project root does not contain a file named `README.md`. If a root README already exists, the method returns without changing it.

**Runtime placeholder:** `$displayName` is the project display name.

**Exact template after substitution:**

~~~markdown
# $displayName

## Attribution

This project was created with [Android IDE](https://github.com/godlovetikum/Android-IDE).

- **Author:** [godlovetikum](https://github.com/godlovetikum)
- **Android IDE repository:** https://github.com/godlovetikum/Android-IDE

## Development

Add the purpose of this project, setup requirements, development commands, and deployment notes here.
~~~

This imported-project path does not create `package.json`, `.gitignore`, or any other project template file. It adds only the missing root `README.md` and leaves existing project files untouched.

## 3. Metadata-folder README

This is not a root README. It is created under the current `.androidide` project metadata directory when that directory exists and lacks its own README:

~~~markdown
# Android IDE project metadata

This folder is managed by Android IDE and stores project-local workspace state.

- `project.json` stores the project name, description, and lifecycle timestamps.
- `workspace.json` stores open tabs, the active tab, cursor positions, and scroll positions.

These files are project-local and travel with the project. Global application preferences remain outside this folder.
~~~

The proposed future metadata-directory identity is `.dev-android-ide`, but the current source still writes and reads `.androidide`. That naming change has not yet been implemented.

## 4. Current template observations

The newly created-project template is a Node-oriented starter containing `package.json`, `npm install`, `npm start`, and `index.js` guidance. The imported-project template is documentation-only and does not infer a language, framework, package manager, or entry point. These are current behaviors recorded for review; they are not being changed in this documentation pass.
